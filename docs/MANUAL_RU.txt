ИНСТРУКЦИЯ: AVITO IPHONE BOT
============================

Что делает бот
--------------
Следит за Авито в Краснодаре (только частные продавцы, сортировка «сначала новые») и присылает
в Telegram-группу выгодные б/у iPhone X, XR, XS, XS Max, 11–17, Air, 16e.
Присылает ТОЛЬКО 4 варианта: целый / разбито стекло экрана / разбито заднее стекло / оба.
Любая другая неисправность — отсев: Face ID, камера, сеть, тач, полосы/пятна на дисплее,
утопленник, не включается, «на запчасти», iCloud/Apple ID, неоригинальные детали,
восстановленные/обменки, только eSIM, лочки. Разбитое защитное стекло — не поломка.
Это настройки по умолчанию: что пропускать, меняется кнопками в Telegram — /filter или «🧰 Фильтр» в меню
(разрешённая поломка пишется в посте строкой «⚠️ поломка: …»).

Как ищет объявления
  • Каждые ~4 секунды (случайно 3–5) — 1-я страница поиска «сначала новые» лёгким запросом списка (JSON,
    ~0,5 с, изнутри браузера бота, как это делает сам сайт). Если JSON недоступен — обычная загрузка страницы.
    Новые объявления разбираются сразу (самые свежие — первыми). После блока Авито бот 5 минут проверяет в 1,5 раза реже.
  • В каждой такой проверке дополнительно смотрится 1-я страница «по дате» одной модели iPhone (по кругу все 32,
    MODEL_SWEEP — моделей за проверку; сейчас 0 (выкл.): Авито режет такие запросы (439), а они — подмножество общего списка).
  • Любая находка («🔥 НИЖЕ РЫНКА» и «✅ В РЫНКЕ», INSTANT_ALL) публикуется МГНОВЕННО по карточке из поиска, а страница объявления
    проверяется сразу после: если там отсев (магазин, iCloud, поломка, снято) — пост удаляется, если всё в порядке —
    подпись поста дополняется описанием со страницы, а фото заменяются на максимальное качество Авито (1280×960). Остальные находки — как раньше, после проверки страницы.
    От появления объявления в поиске Авито до поста — обычно 5–30 с (модерацию Авито ускорить нельзя).
  • Раз в 10 минут — полный проход до 5 страниц через JSON, ~5 с (догоняет пропущенное); только объявления ≤ 24 ч.
  • Ночью 1:00–5:00 — тот же ритм; в это же время в фоне обновляется база цен.
  • Магазины пропускаются: по тексту («наш магазин», «даём гарантию», рассрочка, trade-in…),
    по метке «не частное лицо». Продавец, хоть раз опознанный как магазин, попадает в чёрный
    список (по ссылке на профиль) — все его объявления больше не открываются.
  • Перекупы-частники не отсеиваются. Одно и то же объявление продавца (модель, память, цена)
    публикуется не чаще раза в сутки. Уже опубликованные и уже отсеянные повторно не смотрятся.

Рыночная цена — ТОЛЬКО калькулятор Авито (avito.ru/evaluation/mobile-phones)
  • Раз в сутки, НОЧЬЮ (1:00–5:00) небольшими порциями, бот спрашивает калькулятор по всем
    моделям × памяти × 2 состояниям: Отличное и Хорошее (≈ 200 вилок).
    Днём калькулятор не опрашивается (только по кнопке «🔄 Цены Авито» / /prices).
  • Для каждого объявления берётся ВИЛКА цен (минимум–максимум) для состояния, которое указал продавец
    «Новое» и «Отличное» — по «Отличному»; «Хорошее», «Удовлетворительное», «Требуется ремонт» и не указано —
    по «Хорошему» (решение заказчика 17.10). Нет вилки — берётся соседняя, и в посте пишется «по «…»».
  • Пост — если цена не выше «максимум вилки − 1 000 ₽» (MIN_PROFIT). Дороже — не публикуется.
    Ниже минимума — «🔥 НИЖЕ РЫНКА», внутри вилки — «✅ В РЫНКЕ».
  • Если калькулятор отвечает «слишком часто» (429) — бот ждёт и повторяет, недостающее
    дозапрашивает позже сам. Нет цены для модели — объявление не публикуется.

Проверка объявления
  • Сейчас ИИ выключен (AI_PROVIDER=none): проверка только по ключевым словам, фото не смотрятся.
  • Если продавец не описал состояние — пост с пометкой ⚠️ «состояние не описано — уточнить у продавца».
  • Включить ИИ (Gemini по ключу в .env): AI_PROVIDER=openai. Тогда ИИ смотрит текст и 2 фото;
    его замечания засчитываются, только если о проблеме прямо сказано в тексте.

Пример поста (альбом до 4 фото + подпись):
  🔥 НИЖЕ РЫНКА
  📱 iPhone 15 Pro, 256 ГБ
  💰 36 000 ₽ (рынок Авито 38 000–44 000 ₽, средняя 41 000 ₽)
  ⚠️ уточнить у продавца: iCloud
  ✅ Face ID
  🔋 АКБ 86%
  📝 «начало описания продавца»
  🕒 сегодня в 12:58 (время публикации со страницы объявления)
  📍 Краснодар, район · частное лицо
  🔗 ссылка
Если цена опубликованного снизится — бот ответит на пост «📉 Цена снижена».


1. ЗАПУСК
---------
  1) Включите v2rayN (нужен только для Telegram).
  2) Дважды кликните run.bat. Окно не закрывайте — это и есть работающий бот.
     Упадёт — run.bat сам перезапустит его через 15 секунд.
  3) Откроется окно Chromium — браузер бота для Авито. Не закрывайте его.
  Остановить: в окне run.bat Ctrl+C, затем «Y».
  Не запускайте run.bat дважды — будут работать два бота.

  Первый запуск на новом компьютере: Python 3.12+ (python.org, галочка «Add to PATH»);
  run.bat (и setup_env.bat, open_browser.bat) сам проверит Python, создаст окружение и скачает Chromium (install.bat).


2. VPN, БЛОКИРОВКИ И КАПЧА
--------------------------
  • Авито ходит НАПРЯМУЮ (мимо v2rayN), Telegram — через v2rayN (TG_PROXY в .env).
    v2rayN — режим «системный прокси», НЕ TUN.
  • Блок или капча на мобильном прокси: бот сам меняет IP (по ссылке или ждёт смену по таймеру) и продолжает.
  • Капча админам — только если сменить IP не удалось (не чаще раза в час): картинка и одноразовая ссылка на
    живой браузер бота. Решите с телефона — бот продолжит сам. В логе: «Жду решения капчи…», «Капча решена».
    Ссылка вне домашнего Wi-Fi: TUNNEL=cloudflared в .env (файл tools\cloudflared.exe) — бот сам
    откроет туннель Cloudflare, в логе «Туннель для капчи: https://….trycloudflare.com».
  • Блокировка IP: бот пробует прокси из PROXY_LIST, потом ждёт 10–15 минут.
    Для стабильной работы нужен мобильный прокси РФ (HTTP, со сменой IP по ссылке):
    PROXY_LIST=http://логин:пароль@адрес:порт


3. УПРАВЛЕНИЕ (в личке с ботом, только админы)
----------------------------------------------
  /start — меню с кнопками:
    📊 Статус      — последняя проверка, блокировки, посты за час/сутки, цены калькулятора
    📱 Модели      — включить/выключить модели
    💰 Рынок       — выберите модель → вилки цен Авито (мин–макс и средняя) по памяти и состояниям
    📈 Аналитика   — все модели: вилки цен, тыс. ₽ (отл · хор). Команда /stats
    🔄 Цены Авито  — обновить базу цен калькулятора сейчас (в фоне, ~25 мин, поиск не останавливается)
    🔧 Ремонт      — таблица цен ремонта (в расчёте не участвует)
    ⏸ Пауза / ▶️ Запуск
    🔁 Рестарт     — перезапустить бота (спросит подтверждение; поиск встанет на ~30 с)
  Команды:
    /market 13 Pro [256]   — цены калькулятора по модели
    /prices                — обновить базу цен сейчас
    /add 13 Pro, /remove 13 Pro, /add all, /remove all
    /status, /stats, /pause, /resume, /repair 13 Pro 9000 4000
    /add_here, /remove_here — (в группе) публиковать находки сюда / убрать группу
    /channels              — список групп и каналов для находок; /remove_chat ID — убрать
    /block ссылка          — заблокировать продавца (ссылка на его профиль), /unblock ссылка — вернуть
  Бот сам пишет админам, если 30 минут не может проверить Авито, и когда снова заработал.


3а. ОТЛАДКА И АДМИНЫ ЧЕРЕЗ TELEGRAM (/debug — список)
----------------------------------------------------
  /status_here — в группе (или в теме группы, или в личке): бот присылает «живой» статус, закрепляет его и
                 сам обновляет каждые 10 с (LIVE_STATUS_SEC). Внутри: работает ли, последняя проверка, ритм,
                 блоки, вход в аккаунт, цены калькулятора, за час — проверки/блоки/посты, свежесть, последние посты.
                 /status_off — выключить. Для закрепления дайте боту право «Закреплять сообщения».
  /speed       — скорость и статистика за час, свежесть (опубликовано → бот увидел), последние посты
  /log 50      — последние строки лога · /logfile — весь файл лога · /errors 60 — предупреждения/ошибки за N мин
  /ip          — какой IP видит Авито и есть ли вход в аккаунт · /rotate — сменить IP мобильного прокси
  /screen      — скриншот браузера бота · /check ссылка — пройдёт ли объявление и почему нет (без публикации)
  /browser     — ссылка на живой браузер бота на 15 мин (поиск на паузе): войти в Авито, решить капчу; потом /resume
  /filter      — фильтр поломок: какие пропускать (✅) и какие отсеивать (❌), «По умолчанию» — сброс
  /restart     — перезапустить бота (окно run.bat / служба на сервере поднимет его через ~15 с)
  Админы: /admins — список; /add_admin — ответом на сообщение человека, на пересланное от него сообщение
          или с ID (/add_admin 123456789); /remove_admin — так же. Менять список могут только владельцы из .env
          (ADMIN_IDS), добавленные админы управляют ботом. /myid — человек узнаёт свой ID (работает у всех).
  От имени бота (только владельцы из .env, в личке с ботом): /say текст — в группу; /say_admins текст — всем
  остальным админам в личку. Ответом /say на любое сообщение (фото, видео, файл) — бот перешлёт его копию.


4. ГРУППЫ И КАНАЛЫ ДЛЯ НАХОДОК
------------------------------
  Находки публикуются сразу во все добавленные группы и каналы (одинаковый пост, «📉 Цена снижена» — в каждом).
  Группа: добавьте бота администратором и напишите в группе /add_here.
  Канал: добавьте бота администратором канала (с правом публикации) и перешлите боту в личку любой пост из канала.
  Убрать: /remove_here в группе или /remove_chat ID в личке. Список — /channels.
  Если ни одна группа недоступна — находки придут админам в личку.


5. НАСТРОЙКИ (.env, открыть Блокнотом; после изменений — перезапуск)
--------------------------------------------------------------------
  BOT_TOKEN, ADMIN_IDS, GROUP_CHAT_ID, TG_PROXY — Telegram
  CHECK_INTERVAL_MIN/MAX  полный проход до 5 страниц, минут (10)
  FAST_INTERVAL_SEC       проверка 1-й страницы, секунд (45; 0 — выкл.), FAST_JITTER_SEC — разброс (10)
  DEEP_PAGES              страниц сверх первой (4 → всего 5)
  MAX_AGE_HOURS           максимальный возраст объявления, часов (24)
  MAX_POST_DELAY_SEC      не публиковать находку позже, чем через N секунд после публикации на Авито (0 — без ограничения, по умолчанию).
                          Задержка — наибольшее из: время из поиска Авито (sortTimeStamp), подпись «N минут назад» (у поднятых
                          объявлений она честная) и первое появление у бота. Опоздавшие находки (Авито поздно
                          показал объявление в поиске, цена снизилась или база цен обновилась позже) не публикуются —
                          в логе «Поздно: …», в /speed «пропущено поздних».
  NIGHT_HOURS             ночной режим (1-5); NIGHT_FAST_SEC — проверка 1-й страницы ночью, секунд (0 — как днём)
  LIGHT_PAGES             true — браузер не грузит видео (по умолчанию false; картинки грузятся всегда)
  BLOCK_SLOWDOWN_MIN / BLOCK_SLOWDOWN_FACTOR  после блока N мин проверять 1-ю стр. в K раз реже (5 / 1.5)
  FAST_JSON / FAST_JSON_SEC  лёгкий JSON-опрос 1-й страницы и его интервал, секунд (true / 4)
  INSTANT_BELOW_MIN       мгновенный пост «ниже рынка» до проверки страницы (true; при включённом ИИ не работает)
  FAST_TURBO_SEC / TURBO_AFTER_MIN  «турбо»: проверка раз в N с, если M мин не было блоков (30 / 20; 0 — выкл.)
  MARKET_SOURCE           eval — рынок только из калькулятора Авито
  AVITO_EVAL_CITY         город калькулятора (Краснодар)
  AVITO_EVAL_PER_STEP     сколько вилок калькулятора обновлять за ночной цикл (40)
  MIN_PROFIT, MIN_PROFIT_BROKEN  на сколько ₽ ниже максимума вилки должна быть цена (1000)
  AI_PROVIDER             none — без ИИ; openai — Gemini по AI_BASE_URL / AI_API_KEY / AI_MODEL
  PROXY_URL               мобильный прокси http://логин:пароль@адрес:порт
  PROXY_ROTATE_EVERY      раз во сколько секунд прокси сам меняет IP (120; 0 — нет)
  PROXY_LIST              свои прокси через запятую
  TUNNEL                  cloudflared — ссылка на капчу работает с телефона из любой сети (пусто — только Wi-Fi)
  HEALTHCHECK_URL         адрес мониторинга (healthchecks.io), пусто — выкл.
  MAX_PHOTOS              фото в посте (4)

7. ПЕРЕНОС НА СЕРВЕР И МОБИЛЬНЫЙ ПРОКСИ
---------------------------------------
  Прокси (мобильный РФ, «индивидуальный», протокол HTTP, со ссылкой смены IP) — в .env:
    PROXY_URL=http://логин:пароль@адрес:порт
    FREE_PROXIES=false
    PROXY_ROTATE_EVERY=120   — если IP меняется сам по времени (каждые 2 мин), ИЛИ
    PROXY_ROTATE_URL=ссылка смены IP из личного кабинета прокси (если смена по ссылке)
  При блокировке или капче бот меняет IP и повторяет (без лимита); капча админу — только если смена IP не удалась.

  Сервер (VPS, Ubuntu 22.04/24.04, 2 vCPU / 4 ГБ):
    1) Остановите бота на ПК. Скопируйте папку бота на сервер (WinSCP или scp) вместе с .env и data/bot.sqlite3.
       Вход в Авито после запуска — заново: /browser в Telegram → ссылка на браузер бота → войти → /resume
       (профиль браузера Windows на Linux не читается).
    2) На сервере в папке бота:  sudo bash deploy/setup.sh
    3) В /opt/avito-iphone-bot/.env: HEADLESS=true, TG_PROXY= (пусто), PUBLIC_URL=http://IP_СЕРВЕРА:8080,
       PROXY_URL, PROXY_ROTATE_EVERY, FREE_PROXIES=false
    4) sudo systemctl restart avito-bot      — запуск (сам перезапускается после сбоев и перезагрузки)
       sudo journalctl -u avito-bot -f       — лог в реальном времени
    На ПК бота после переноса остановите — два бота одновременно работать не должны.
